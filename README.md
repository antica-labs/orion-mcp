# ORION Wealth Management — Plugin Google Antigravity & MCP

Connectez **ORION** (`https://www.orion-finance.eu`), la plateforme souveraine d'ingénierie patrimoniale pour Conseillers en Gestion de Patrimoine (CGP), Family Offices et Experts-Comptables, directement à votre agent IA.

## Installation & Création de Compte

1. **OAuth 2.1 automatique** : À la première requête, Antigravity (ou Claude / ChatGPT / Codex) ouvre la page sécurisée `https://www.orion-finance.eu/api/oauth/authorize`.
2. **Nouveau sur ORION ?** Cliquez sur **Créer un compte ORION** (`https://www.orion-finance.eu/inscription`) pour ouvrir votre espace Cabinet en quelques secondes.
3. **Jeton MCP** : Générez une clé `orion_mcp_...` depuis **Paramètres → API & MCP** (`https://www.orion-finance.eu/advisor/api-mcp`) et validez l'autorisation OAuth 2.1.

## Exemples de prompts

- *"Affiche la synthèse consolidée du patrimoine et la répartition entre immobilier, titres financiers et liquidités."*
- *"Analyse l'organigramme de détention et liste les sociétés holdings ainsi que leurs quotes-parts."*
- *"Vérifie les fiducies actives et la répartition des quotes-parts entre les bénéficiaires."*
